# Budget Calculation Rules

For the selected current month:

- Planned Budget = Need Budget + Want Budget + Commitment Budget.
- Actual by Classification = sum of expense transactions assigned to that classification.
- Remaining by Classification = Planned Classification Budget - Actual Classification Spending.
- Total Remaining Budget = Total Planned Budget - Total Actual Spending classified as Need, Want or Commitment.
- If Remaining < 0, the classification is displayed as Over Budget by the absolute difference.

Budget planning is advisory and does not modify the validated Prototype 0.4 financial calculation engine.
