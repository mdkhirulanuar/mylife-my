# Prototype 0.5 Acceptance Criteria

1. User can set monthly Need, Want and Commitment budgets.
2. Total planned budget reconciles to the three classifications.
3. Current-month actual spending is mapped to the correct classification.
4. Remaining and over-budget values reconcile to RM0.01.
5. Budget survives reload.
6. Previous-month transactions do not affect current-month budget actual.
7. Prototype 0.4 financial calculations and legacy tracking functions remain regression-green.
